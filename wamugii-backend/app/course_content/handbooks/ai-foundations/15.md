Face unlock, voice assistants, Google Translate, crop-disease apps and ChatGPT all run on the same engine: the **neural network**. The name sounds mysterious, but the core idea is surprisingly simple. A neural network is built from a very large number of tiny, simple calculators, connected in layers. Each one does a little arithmetic. Together, they can learn astonishingly complex patterns.

In this chapter you will open the engine and see how it is built. You need only multiplication and addition.

## Inspired by the brain, built with maths

Neural networks were **loosely inspired** by brain cells (neurons), which receive signals from other cells and "fire" when the combined signal is strong enough. But an artificial neural network is really a large **mathematical function**: numbers go in, are multiplied, added and transformed many times, and numbers come out. It does not think or feel like a brain. Keep the brain comparison as a helpful picture, not as a fact.

## One neuron

A single artificial neuron does three things:

1. It takes some **inputs** (numbers).
2. It multiplies each input by a **weight**, adds the results together, and adds a **bias**.
3. It passes the total through an **activation function**, which decides how strongly the neuron "fires".

- A **weight** says how **important** an input is. A large positive weight means "this input pushes strongly towards yes"; a negative weight means "this input pushes towards no".
- The **bias** is a starting offset. It sets how easily the neuron fires, regardless of the inputs.

[[fig:neuron|One neuron deciding whether to carry an umbrella. Each input is multiplied by its weight, the results and the bias are added, and the activation function decides the output.]]

:::example Worked example: the umbrella neuron
Inputs (each between 0 and 1): cloudiness = 0.9, rain forecast = 0.8, already raining = 0.
Weights: 0.5, 0.8 and 1.0. Bias: −0.6.

Step 1, multiply each input by its weight: 0.9 × 0.5 = 0.45; 0.8 × 0.8 = 0.64; 0 × 1.0 = 0.
Step 2, add them and the bias: 0.45 + 0.64 + 0 − 0.6 = **0.49**.
Step 3, activation: using a simple rule "fire if the total is above 0", the result is positive, so the neuron **fires**: take the umbrella.

On a sunny day (cloudiness 0.2, rain forecast 0.1, already raining 0): 0.1 + 0.08 + 0 − 0.6 = **−0.42**. Negative, so the neuron does **not** fire.
:::

Notice the role of the bias: −0.6 means the neuron needs fairly strong evidence of rain before it fires. A bias of −0.2 would make it a more "careful" neuron that fires more easily.

**Learning** means finding good values for all the weights and biases. In this example we chose them by hand. In a real network there may be millions or billions of them, and they are found automatically from data, as you will see in Chapter 16.

## Layers

Neurons are arranged in **layers**. Each neuron in a layer receives the outputs of the layer before it.

[[fig:network|A small neural network. Every neuron in one layer is connected to every neuron in the next. Early layers find simple patterns; later layers combine them.]]

| Layer | Job | Example: reading a handwritten digit |
|---|---|---|
| **Input layer** | Receives the raw data | 784 numbers, one for each pixel of a 28 × 28 image |
| **Hidden layers** | Build up patterns step by step | First small strokes and edges, then curves and loops, then digit-like shapes |
| **Output layer** | Gives the answer | 10 neurons, one for each digit 0–9; the highest wins |

A network with **many hidden layers** is a **deep** network. That is where the name **deep learning** comes from.

:::example Worked example: how many numbers must be learned?
A small digit-reading network has 784 inputs, two hidden layers of 16 neurons and 10 outputs. Every neuron connects to every neuron in the next layer.

- Weights between input and hidden layer 1: 784 × 16 = **12,544**.
- Between hidden layer 1 and hidden layer 2: 16 × 16 = **256**.
- Between hidden layer 2 and the output: 16 × 10 = **160**.
- Biases: one per neuron in the hidden and output layers: 16 + 16 + 10 = **42**.

Total: 12,544 + 256 + 160 + 42 = **13,002** parameters, for a tiny network. Large language models have **billions**.
:::

## Why depth helps

Each layer builds on the one before. In image recognition:

- **Early layers** detect simple **edges**: light-to-dark changes, lines at different angles.
- **Middle layers** combine edges into **shapes and parts**: circles, corners, eyes, wheels, the spots on a diseased leaf.
- **Later layers** combine parts into **whole objects**: a face, a car, "cassava mosaic disease".

The same building-up happens with sound (sounds → syllables → words) and text (letters → words → meanings). Nobody tells the network which edges or shapes to look for; it **discovers** useful patterns during training because they help reduce its errors. This automatic building of features is exactly what rule-writing failed to do in the 1980s (Chapter 2).

## Activation functions

Why not just add and multiply? Because without an activation function, stacking many layers would still produce only a **straight-line** model: combining straight lines always gives a straight line. Activation functions add the **bends** (non-linearity) that let networks learn curved, complex patterns.

| Activation | What it does | Example values | Typical use |
|---|---|---|---|
| **ReLU** | Keeps positive numbers, turns negatives into zero | 2.3 → 2.3; −1.5 → 0 | Hidden layers; simple and very common |
| **Sigmoid** | Squeezes any number into the range 0 to 1 | 0 → 0.5; 3 → about 0.95; −3 → about 0.05 | A single yes/no probability |
| **Softmax** | Turns a list of scores into probabilities that add up to 1 (100%) | see below | The output layer when there are several classes |

:::example Worked example: softmax by hand
A leaf-disease network gives three raw scores: healthy **2.0**, mosaic **1.0**, brown streak **0.1**. Softmax works in two steps.

1. Raise the number e (about 2.718) to each score: e^2.0 ≈ 7.39; e^1.0 ≈ 2.72; e^0.1 ≈ 1.11. These are all positive, and bigger scores grow much bigger.
2. Divide each by the total (7.39 + 2.72 + 1.11 = 11.22):
   - healthy: 7.39 ÷ 11.22 ≈ **0.66** (66%)
   - mosaic: 2.72 ÷ 11.22 ≈ **0.24** (24%)
   - brown streak: 1.11 ÷ 11.22 ≈ **0.10** (10%)

The probabilities add up to 100%, and the app can report "healthy, 66% confidence". A 66% answer is not very sure, which is useful information: the app might ask the farmer for a clearer photo.
:::

## Special network designs

The fully connected network above is the basic form. Over time, researchers designed special structures for special kinds of data.

- **Convolutional neural networks (CNNs)** are designed for **images**. Instead of connecting every pixel to every neuron, a CNN slides small **filters** (for example 3 × 3 pixels) across the image, looking for the same pattern everywhere. A filter that detects a leaf spot works whether the spot is in the top corner or the middle. This makes CNNs far more efficient for images. They power crop-disease apps, medical-scan analysis and face recognition.
- **Recurrent neural networks (RNNs)** process **sequences** one step at a time, keeping a memory of what came before. They were used for speech and text before 2017, but they are slow to train and struggle to remember things far back in long sequences.
- **Transformers** process a whole sequence at once using **attention** (Chapter 17). They replaced RNNs for language and are now used for images, audio and more.

## The cost of power

Deep networks are powerful, but that power has costs:

- **Data:** they usually need large amounts of labelled data.
- **Computing:** training needs powerful GPUs and a lot of electricity.
- **Explainability:** with millions of weights, it is very hard to say **why** a network made a particular decision. This "black box" problem is the subject of Chapter 20.

For a small table of numbers (a few thousand loan records), a simpler model from Chapter 9 is often just as good and much easier to explain. Neural networks shine on **images, sound and language**.

:::mistake Common mistake
Imagining that each neuron stores a human idea, such as "this neuron means cat". Sometimes a neuron does respond to something recognisable, but usually knowledge is **spread** across many weights, in patterns that do not match human words. This is one reason networks are hard to explain.
:::

:::rwanda In Rwanda
Kinyarwanda speech recognition and translation tools are built with deep neural networks. Their quality depends heavily on how many hours of recorded Kinyarwanda speech and how much Kinyarwanda text they learn from. Community projects that collect and share such data, with permission, directly improve the networks that serve Rwandans.
:::

## Summary

- A **neuron** multiplies its inputs by **weights**, adds a **bias**, and applies an **activation function**. Learning means finding good weights and biases.
- Neurons form **input, hidden and output layers**. Many hidden layers make a network **deep**.
- Depth lets networks build **edges → shapes → objects**, discovering useful features automatically.
- **Activation functions** add non-linearity. **ReLU** for hidden layers, **sigmoid** for one probability, **softmax** for several classes.
- **CNNs** suit images, **RNNs** sequences (older), **transformers** language and more. Power costs data, computing and explainability.

## Key terms

- **Neural network** — a model made of many simple calculating units (neurons) connected in layers.
- **Neuron** — a unit that computes a weighted sum of its inputs plus a bias, then applies an activation function.
- **Weight** — a number showing how strongly an input influences a neuron.
- **Bias (neuron)** — a starting offset added to a neuron's weighted sum.
- **Activation function** — a function that adds non-linearity and decides how strongly a neuron fires.
- **Input layer** — the layer that receives the raw data.
- **Hidden layer** — a layer between input and output that builds up patterns.
- **Output layer** — the layer that gives the final answer.
- **Deep network** — a neural network with many hidden layers.
- **ReLU** — an activation that keeps positive values and turns negatives into zero.
- **Sigmoid** — an activation that squeezes any number into the range 0 to 1.
- **Softmax** — a function that turns scores into probabilities adding up to 1.
- **Convolutional neural network (CNN)** — a network that slides small filters over images to find patterns anywhere.
- **Recurrent neural network (RNN)** — a network that processes sequences step by step with a memory.

## Think deeper

1. Change the umbrella neuron's bias from −0.6 to −1.2. Does it still fire for cloudiness 0.9, rain forecast 0.8, already raining 0? What kind of person does this neuron now behave like?
:::answer
The total becomes 0.45 + 0.64 + 0 − 1.2 = −0.11, which is negative, so the neuron does not fire. It now needs stronger evidence before taking an umbrella, like a person who only carries one when rain is almost certain, for example when it is already raining.
:::
2. A network outputs scores of 3.0 for "cat" and 3.0 for "dog". What will softmax give, and what should an app do with that result?
:::answer
Equal scores give equal probabilities: 50% cat and 50% dog. The network is completely unsure between the two. A good app should not pretend to know; it should say it is unsure, perhaps ask for another photo, or pass the case to a person.
:::
3. Why would a CNN be a better choice than a fully connected network for recognising cassava diseases in photos?
:::answer
A phone photo has hundreds of thousands of pixels, so connecting every pixel to every neuron would need an enormous number of weights and a huge amount of data. A CNN uses small filters that slide across the image and reuse the same weights everywhere, so it needs far fewer parameters, and it can recognise a disease spot wherever it appears on the leaf. This makes it more efficient and better at generalising.
:::
